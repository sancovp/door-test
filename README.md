# door-test

**This repository is a wording test, not a project.** Each folder holds one version of the same front page for a
made-up skills collection. The numbers and skill names in them are invented for the test. The question being tested:
when someone's AI assistant fetches the page, which wording gets the facts through?

Folders `a` to `f` are the versions. `tome/` is a stand-in for the larger thing they point to.
