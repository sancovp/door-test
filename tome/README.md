# The tome

The whole book of this author's work, organized by area. The `skills` collection is one part of it, by kind.

| area | skills | agents | harnesses |

| Memory | 33 | 2 | 0 |

| **all** | **412** | **31** | **6** |

## What is here that the skills collection does not have

- the 31 agents, each named with the skills it carries
- the 6 harnesses that run them
- for every skill, what uses it and what it is part of
- one search: describe a task, get the skill, agent or harness for it

## Install any part

`/plugin install <area>@tome` installs one area with its agents and harness. `/plugin install tome@tome` installs all of it.

(This is a stand-in written for a wording test. The numbers are invented.)
